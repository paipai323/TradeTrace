Restart resume limits

Optional clean-restart handoff only, with a maximum 30-second gap. The same account, fresh quotes, frozen cancellation and candle continuity must pass. Crashes, reviews, attempted/submitted orders, missed candles and unsafe checkpoints stay disarmed. No order is evaluated on the recovery poll. The first restart after installing this feature still needs manual Start.

Sleep protection limits

Automatic idle-sleep protection while setups monitor, wait for a retest, or await order review. The screen can turn off. Keep the laptop plugged in: Windows may end these requests on battery. Manual sleep, hibernation, shutdown, power loss and network failures can still interrupt monitoring. Existing interruption checks and explicit restart requirements stay active.

Setup invalidation settings

An independent guard, active from Start through order review. Invalidation wins over an entry signal. It never closes positions or cancels orders already sent. Draft changes need a new Start.

Entry quality settings

Checked when conditions pass and again before sending. A failed check skips this setup once, with no retry. Applies to condition orders only.

Distance to a zone is zero inside it, otherwise measured from its nearest edge. A level or observed BOS/MS break uses its price. For gold, 5 means 5.00 in price, not five ticks.

RR uses the nearer of the order TP and this target. It never changes the order TP. Market checks include the 20-point adverse-entry allowance. Price RR excludes costs and actual slippage.

Automatic trade plan settings

Uses the BUY / SELL side in Order. Overrides ticket entry, SL / TP and lot sizing for condition entries only. Start freezes these settings.

BUY requires Bid above the matching broken level; SELL requires Ask below it. Checked again when sending. Does not apply to retest limits.

Buy SL uses a confirmed swing low; sell SL uses a confirmed swing high. No swing or invalid price means no order. Lots round down to broker steps. Market sizing includes the app's 20-point deviation allowance. Costs and actual slippage can change the result. Retests require broker-supported expiry and never turn into stop orders.

How monitoring works

Automatic entry makes one attempt per start, requires ticket SL and TP or an enabled automatic trade plan, and allows additional positions or pending orders on the same symbol. Empty lists act immediately. No retries. Monitoring runs on the local server and continues through hidden tabs, minimization, reload and chart changes. Keep the computer, TradeTrace server and MT5 running. MT5 disconnect, account change or a long polling interruption stops monitoring. Server restart never resumes it. Review mode still needs confirmation; no phone alerts.
